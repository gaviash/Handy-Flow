Sous le capot

Un thème coûte 13 lignes de CSS. Le reste se calcule. Ajouter un neuvième thème plus tard prend dix minutes.

Un thème, en entier

/* src/styles/themes.css — une ligne par couleur, clair puis sombre */
[data-palette="sauge"] {
  --bg:          light-dark(#f5f3e8, #0f1916);
  --ink:         light-dark(#171a16, #eef0e6);
  --accent:      light-dark(#12443d, #8fd3bd);
  --on-accent:   light-dark(#f5f3e8, #0c2420);
  --accent-text: light-dark(#12443d, #8fd3bd);
  --side:        light-dark(#12443d, #0b2420);
  --pill:        light-dark(#12443d, #173a33);
  /* … pill-ink, pill-accent, icon-* */
}
/* Mode : seul color-scheme change */
html[data-mode="dark"] { color-scheme: dark; }

Ce qu’il faut changer

  1. Réglages : ajouter palette à côté de theme (déjà Système/Clair/Sombre), plus headings, density, overlay_style.
  2. theme.css : remplacer les paires --light-*/--dark-* par les palettes ci-contre ; les noms de tokens existants restent des alias.
  3. theme.ts : poser data-palette en plus de data-theme ; l’overlay lit les deux.
  4. Polices : Figtree + Instrument Serif en woff2 locaux (OFL), aucune requête réseau.
  5. Icônes : un SVG maître, tauri icon pour l’icône d’installation ; l’icône de la barre et de la fenêtre change à chaud.
